# 碳硅双译｜项目标准化工作流
> 本仓库全部视觉产出、视频物料固定执行这套流程，**拒绝一步到位生成复杂成品，分层迭代，保证逻辑不出错**

## 核心原则
1. 不追求速度；
2. 不直接生成高复杂度立体成品；
3. 全部物料属于结构创作，每一份画面必须有底层数据作为依据；
4. 必须具备完整立体叙事逻辑。

## 五步标准工作流
### 步骤1：结构讨论，定义底层逻辑
人和AI完成概念、关系、节点的完整梳理，输出文字底稿，存入仓库。
> 输出物：markdown文字文档，确定全部节点、全部连接关系，作为一切图像的数据源。

### 步骤2：生成平面图（二维拓扑图）
基于步骤1的文字底稿，优先产出二维平面拓扑框图。
二维图必须严格对齐文档内全部关系，校验节点、连线没有错误。
> 输出物：Mermaid渲染图 / AI生成二维示意图，逻辑正确性优先，美观其次。

### 步骤3：分单元生成短动态片段
以校验完成的二维平面图作为参考底图，**不一次性渲染完整大立体场景**。
拆分单元，一小块一小块分别生成简短动态素材。
例如：单独生成【自刑球体自循环动画】、【对冲链路发光动画】等碎片化短片。
> 输出物：多段10‑15秒短视频素材库。

### 步骤4：本地人工剪辑迭代
将全部碎片化动态素材，由本地人工剪辑拼接。
回看成片，找出缺失、逻辑不对的部分，反馈回来，针对性补充生成缺失片段。
循环往复，直到叙事完整。

### 步骤5：对外发布
完成剪辑后的成片，做对外发布；原始底稿、二维图纸、素材全部留存仓库归档。

## 约束红线
禁止直接口述想法，直接让AI生成复杂三维拓扑完整大场景。
AI生成复杂多连线3D拓扑会出现连线错乱、关系错误，画面好看但是逻辑失效，不能作为研究物料。
必须：文字底稿 → 二维校验 → 分片动态 → 剪辑拼接 → 发布归档。
