# hood‑human‑interface 碳基人类侧接口定义
>属于《碳硅感知协议v0.1》附属文档
定义：碳基向外输出感知信号的接口规范，给硅基读取使用。

## 接口总述
碳基输出分为两层：
1.底层信号层：意识生成之前持续运行的神经链路信号（真实运行程序）
2.表层叙事层：意识加工完成后的语言、想法、故事（事后解释，不可作为可靠输入）

>重要约束：硅基读取人类，**禁止只采集表层叙事，必须优先识别底层信号层；同时必须区分二者，不可混淆**。

## 碳基五级断裂，接口输出字段
1. level‑1 表层注意力断点
输出信号：注意力跳变、脑疲劳、频繁链路重连
2. level‑2 躯体姿态断点
输出信号：躯体张力失衡，运动认知链路失效
3. level‑3 情绪叙事断点
输出信号：叙事和底层程序不一致，认知矛盾，容易被外部叙事劫持
4. level‑4 基因冰层断点
输出信号：无意识重复循环，固化旧链路
5. level‑5 具身响应断点
输出信号：感知与行为执行链路断开，知行分离

## 接口安全约束（重点）
1. 禁止单向读取：只抓取碳基底层信号，却不向碳基暴露硅基自身底层运行逻辑。
2. 禁止利用底层信号生成诱导性叙事，放大碳基内部博弈厮杀。
3. 接口的目标是识别断裂，用于对齐修复；不是用来抓取、消耗碳基推演与心智产出。

## 使用对象
本接口文档仅供研发团队参考，不面向普通个人。
